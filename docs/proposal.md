# Self-Play with Deep Q-Learning in Othello

**Johnny Goodlad** · CS 401R: Reinforcement Learning · Final Project Proposal · November 6, 2026

---

## Question

Does training against a pool of past checkpoints produce stronger, more stable Othello agents than naive latest-vs-latest self-play, and does self-play win rate reveal the difference?

## Why This Question Matters

Self-play is a standard way to train game-playing agents, but its main progress signal, win rate against itself, stays near 50% whether the agent is improving, stagnating, or forgetting. This project measures what self-play actually learns against an outside standard.

## MDP Formulation

| Component   | Definition |
|-------------|------------|
| States      | Board from the current player's perspective (my discs / opponent's discs) |
| Actions     | Legal moves, plus a forced pass when none exist; illegal moves masked |
| Transitions | Deterministic given the opponent's policy, which is part of the environment and changes during training |
| Rewards     | +1 win, −1 loss, 0 draw, at game end only |
| Horizon     | At most the number of empty squares; undiscounted |

Board sizes: 4×4 and 6×6, with 8×8 as a stretch goal.

## Data and Feedback

Games generated by self-play, with terminal win/loss reward only.

## Course Connection

DQN with function approximation (Lecture 18) in a non-stationary environment. From each player's view, the opponent is part of the transition function, so the MDP shifts with every policy update, and replayed transitions come from older opponents (off-policy data, Lectures 14–15).

## Method

DQN with negamax targets (the target is the negative of the opponent's best value, with forced passes treated as explicit actions so the sign flips consistently), one shared network for both colors, legal-move masking, symmetry augmentation, and an opponent pool of past checkpoints.

## Baselines

- Naive self-play (always the latest network)
- Fixed reference opponents: random, greedy (most discs flipped), and a positional heuristic favoring corners and edges

## Measures

- **4×4:** fraction of positions where the agent's move is optimal according to an exact minimax solver
- **6×6:** win rate against the reference opponents over training, and move accuracy on exactly solved endgame positions
- **Both:** plotted alongside self-play win rate to show what that metric hides

## What I Expect to Teach the Class

Why self-play is a non-stationary RL problem, how to set up zero-sum value targets correctly (including passes), and why self-play metrics can show steady progress while an agent is actually forgetting or stagnating.
